
# Smartphone Market Analysis

**Author:** Avadhesh Sahani

**Tools:** Excel | PostgreSQL | Power BI

## Project Overview
Analyzed 915 smartphone and tablet records from 18 companies across 5 regional markets using PostgreSQL and Power BI.

The project explores brand performance, hardware specifications, RAM, battery capacity, screen sizes, and India pricing trends.

## Dataset Summary
- 915 records and 15 columns
- 18 smartphone companies
- 908 distinct models
- 5 regional pricing markets
- 0 duplicate records

## SQL Analysis
Performed 7 analytical queries using:
- GROUP BY and HAVING
- Subqueries and CTEs
- Aggregate functions
- Window functions

## Power BI Dashboard
Created a 2-page interactive dashboard featuring:
- Brand-wise model analysis
- Average price trends
- RAM and battery analysis
- Company performance comparison
- Interactive slicers and KPI cards

## Key Findings
- Average RAM: 7.79 GB
- Average battery: 5,030 mAh
- Average India price: ₹51,070
- Maximum RAM: 16 GB
- Maximum battery: 11,200 mAh
